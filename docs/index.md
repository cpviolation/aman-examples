# AmAn examples

Amplitude-analysis models and studies built on [AmpForm](https://ampform.rtfd.io) and
[TensorWaves](https://tensorwaves.rtfd.io) of [ComPWA](https://compwa.github.io), with
[JAX](https://jax.readthedocs.io) as computational backend. They reproduce the examples
of [cpviolation/tfa_examples](https://github.com/cpviolation/tfa_examples), which uses
AmpliTF and TFA2.
